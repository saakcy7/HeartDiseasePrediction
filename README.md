# Heart Disease Prediction System

A machine learning based Heart Disease Prediction System developed using Python, Scikit-learn, and Tkinter GUI.

The system predicts whether a patient has heart disease based on medical parameters such as age, cholesterol, blood pressure, chest pain type, and heart rate.

---

# Features

- Heart disease prediction using Machine Learning
- Random Forest classifier
- Data visualization using Seaborn and Matplotlib
- GUI application using Tkinter
- Multiple algorithm comparison
- Confusion matrix and classification report
- IEEE report included

---

# Algorithms Used

- Random Forest
- Logistic Regression
- Decision Tree
- K-Nearest Neighbors (KNN)

---

# Best Model

Random Forest achieved the highest accuracy:

| Algorithm | Accuracy |
|------------|------------|
| Random Forest | 85% |
| Logistic Regression | 77% |
| Decision Tree | 74% |
| KNN | 74% |

# Installation

Clone the repository:

```bash
git clone https://github.com/saakcy7/HeartDiseasePrediction.git
```

Move into project folder:

```bash
cd HeartDiseasePrediction
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

# Run the GUI Application

```bash
python app.py
```
